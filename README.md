# Workspace Staff Manager

## Overview

Workspace Staff Manager is a web application designed to help companies manage employee assignments visually on an office floor plan. Built for the WorkSphere project, it aims to provide a simple and interactive way to organize and move staff according to their roles, with clear zone restrictions.

## Features

- Add, move, and delete employees on a visual floor plan
- Role-based zone assignment (e.g., only receptionists in Reception)
- Responsive design for desktop and mobile
- Drag & drop functionality for staff placement
- Display detailed employee info (photo, name, role, contact, experience)
- Edit and filter employees
- Save workspace state locally (localStorage support)

## Zones and Allowed Roles

| Zone          | Allowed Role(s)      |
|---------------|---------------------|
| Reception     | Receptionist        |
| Conference    | All Employees       |
| Server Room   | IT Technician       |
| Security Room | Security Staff      |
| Staff Room    | All Employees       |
| Archives      | Archivist           |

## Usage

- Use the form to add employees with their details.
- Drag and drop employees into their allowed zones.
- Edit or delete employee information when needed.
- Use search/filter to find employees easily.
- Workspace state is saved on your device, so you won’t lose data if you refresh.

## Tech Stack

- HTML5, CSS3, Bootstrap
- JavaScript (Vanilla)
